# 写作、公式与引用示例

## 正文直接讲知识

避免：

> PPT 的开盘例子说明的是意愿需求。此处只是教学示意，不是对某只股票当前报价的描述。

采用独立例题框，直接给出设定：

> 设报价为 150 元，老王想卖出 200 股，老张想买入 300 股。两人的净需求合计为 100 股；全市场超额需求还需汇总其他参与者的意愿。

来源写在 TeX 注释中。例子需要的“设”或“假设”应保留，使读者知道给定条件。

避免把“不能混淆”“并不保证”等提醒堆在正文；直接说明关系：

> 总持仓对应证券总供给，净交易量对应持仓的变动。出清时，净交易量之和为零。

数学上必要的区分仍应讲清，如序数效用、拟凹与凹、净卖出与空头、实际禀赋可市场化与完全市场。

## 行间公式后的分段与首行缩进

行间公式后转入新的说明段、证明步骤或结论段时，在 `\]`、`\end{equation}`、`\end{align}` 等关闭公式环境的命令后空一行。例如：

```tex
\[
 X^{\mathsf T}m_k=S,\qquad
 (m_k)_\omega=\frac{\partial_\omega U_k}{\partial_0U_k}.
\]

两人之差满足 $X^{\mathsf T}(m_k-m_{k'})=0$。当 $X$ 行满秩时，……
```

源码只换行而不空行时，公式后的文字仍按同一段续排，通常顶格；空行结束上一段，新段的首行缩进由项目样式控制。优先用空行表达分段，不用 `\\`、手工空格或 `\hspace` 模拟段落缩进。

按语义分段：若公式后的文字继续原句或紧接着解释其中的符号，可保持同一段。空行放在整个行间公式环境结束之后，不放进 `equation`、`align` 或内部的 `aligned` 等数学环境。编译后检查实际缩进和段距。

## 优化问题的约束排版

多条约束用 `aligned` 分行，并用 `\left\{` 和 `\right.` 生成左大括号。

```latex
\[
\begin{aligned}
 \min_z\quad &\frac12 z^{\mathsf T}\Sigma z\\
 \text{s.t.}\quad &
 \left\{\begin{aligned}
 z^{\mathsf T}\bar r&=\bar r_p,\\
 z^{\mathsf T}\iota&=1.
 \end{aligned}\right.
\end{aligned}
\]
```

单条约束与 `s.t.` 同行。

```latex
\[
\begin{aligned}
 \min_z\quad &\frac12 z^{\mathsf T}\Sigma z\\
 \text{s.t.}\quad &z^{\mathsf T}\iota=1.
\end{aligned}
\]
```

## underbrace 的教学作用

目的在于建立“公式中的这一块是什么、为什么在这里”的对应关系。已有用法包括：消费等于禀赋加减证券交易支付；将直接禀赋与初始证券支付合并为总禀赋；识别证券和商品市场出清；从组合收益中认出已构造基金的收益。

### 给关键项标注经济角色

```tex
\[
c_{k,0}
=\underbrace{e_{k,0}}_{\text{初始禀赋}}
-\underbrace{S^{\mathsf T}\theta_k}_{\text{证券交易净支出}}.
\]
```

按读者需要选择标注项或整体，不要求每个符号都加注。若正文已充分解释且公式很简单，可以不加。

### 从表达式中识别一个已定义对象

```tex
\[
c_{k,1}
=\underbrace{(\varepsilon_{k,1}+X\bar\theta_k)}_{e_{k,1}}
+X\theta_k.
\]
```

或者在收益分解中用 `\underbrace{x_F+\beta_z\tilde y}_{\tilde x_{z_0}}` 表示前面已构造的组合收益。对象必须先定义，维度和经济意义须正确。

### 给等式标明均衡条件

```tex
\[
\underbrace{\sum_{k=1}^{K}\theta_k(e_k,S)=0}_{\text{证券市场出清}}.
\]
```

注释中文放在 `\text{}` 中，保持简短。长解释放在公式前后；较长推导用 `aligned` 等按等号对齐，避免注释宽度拉散整行或造成溢出。多层 underbrace 只在确实要同时识别局部项与整体关系、且版面清楚时使用，优先考虑拆行或正文解释。禁止嵌套内容框的规则不等于禁止数学括注。

## 完整证明的组织

命题“在 H 下，A 当且仅当 B”需要：

1. 在 H 与 A 下推出 B；
2. 在 H 与 B 下推出 A。

若 B 是待刻画的性质，则 A⇒B 是充分性，B⇒A 是必要性。实际书写应把箭头与具体条件同时写出，避免只列标签。

多个条件可用 A⇒B⇒C⇒A 的闭环证明；说明每条箭头用到的假设。必要时补引理、构造或反例，勿把单个方向的计算当作完整等价证明。关键不等式说明依据，例如凹性、条件 Jensen、迭代期望；涉及极限、积分或期望交换时核查相应条件。

## 跨章一致性检查示例

检查的是数学对象、经济含义和适用条件的一致性，不能只做符号查重或全局替换。

| 对象 | 检查要点 |
| --- | --- |
| 证券组合 | 当前变量表示总持仓、净交易量，还是财富权重？预算约束、支付与出清条件是否使用同一口径？ |
| 价格和收益 | 区分价格、净收益率、总收益率和超额收益；现金流、贴现和期末财富公式是否匹配？ |
| 效用与偏好 | 序数效用与期望效用的变换要求是否区分？调用凹性、风险厌恶结论时是否满足对应框架与条件？ |
| 支付矩阵与索引 | 状态为行、证券为列等约定是否一致？组合乘法、转置和求和上下限是否维度相容？ |
| 概率和价格权重 | 实际概率、状态价格、风险中性概率等对象是否明确区分，归一化与期望口径是否匹配？ |
| 假设和结论 | 完全市场、无摩擦、无套利、可卖空、效用定义域等条件是否被正确沿用或明确变更？ |

例如：前文以总持仓 $h_k$ 表示出清条件 $\sum_k h_k=\theta_M$，后文改用净交易 $\theta_k=h_k-\bar\theta_k$ 时，应对应写 $\sum_k\theta_k=0$，并让预算式同步采用净交易口径。两种表示可以等价，不能仅为“符号统一”把两式中的变量换成同一个字母。

处理一个章节时，可按需要暂列“对象—首次定义位置—当前含义与条件—相关后文位置—处理结果”，帮助追踪依赖；无需每次生成独立清单文件。新发现的全书性约定以来源核验后为准，不能从一个例题抽取为全书硬规则。

## 正确的 LaTeX 引用

### 当前讲义内部

- 正文与习题使用主文件定义的深蓝色引用宏（`WJReferenceColor`，`#244A78`）。把类型、编号、条款或子图标记及简短说明纳入同一链接。跨章或读者仅看编号难以辨认时补简短名称，附近已说明时可以省略，较长背景放正文或脚注。
- 章节、定义、定理、命题、例题、图表和习题用 `\WJRef{标签}{前缀}[后缀]`，例如 `\WJRef{sec:wj-seven-small-risk}{第~}[~节（小风险展开与绝对风险厌恶系数）]`。章节标签放在标题命令后，其他编号对象的标签绑定实际计数器，沿用所需的原书编号。
- 公式用 `\WJEqRef{标签}{前缀}[后缀]`，宏会给编号加圆括号。用有编号的 `equation`、`align` 等环境绑定语义明确且唯一的标签，多行公式引用具体编号所在行。
- 只链接概念名称，或需要组合多个编号并跳到其中一个具体目标时，用 `\WJLink{目标标签}{显示文字}`，内部用 `\ref*` 取号。例如 Ross 定理的引用文字包含定理号和条款号，落点是对应条款。已有无编号的 `\hypertarget` 可用 `\hyperlink{锚点}{\textcolor{WJReferenceColor}{显示文字}}`，保留精确落点。页码引用沿用 `\pageref`。
- 图引用的落点应在图上方。原位或独立 TikZ 图可沿用 `tex/_shared/wj-figure-styles.tex` 中的 `\WJFigureStart{标签}` 和 `\WJFigureCaption{图题}`，在图前绑定真实计数器及标签，图后排图注。已有章节专用计数器时沿用其编号。标准浮动图表核对 `\caption` 后的标签所对应的实际跳转位置。多面板可写 `\WJRef{fig:...}{图~}[（a）]`。
- 引用某小问的解答时，教师版链接到对应解答，隐藏解答的学生版保留题号和小问号。仅习题版没有正文目标时，沿用 `\ifdefined\WJHandoutKnowledge` 或已有的标签存在性判断，让该模式下的文字仍然通顺。

```tex
\begin{equation}
  \sum_{k=1}^{K}\theta_k(e_k,S)=0
  \label{eq:wj-market-clearing}
\end{equation}
由\WJEqRef{eq:wj-market-clearing}{市场出清条件~}可得……
```

例如，正文用 `\WJRef{fig:wj-consumption-preferences}{图~}` 引用下图。

```tex
\WJFigureStart{fig:wj-consumption-preferences}
% 此处排图
\WJFigureCaption{消费集与偏好的几何性质}
```

图注、图下解释和正文引用各有作用：图注标识对象，图下解释交代示例设定，正文引用连接所讲的概念或结论。编译后同时核对显示的图表编号与 PDF 跳转目标；只有标签存在或链接可点击，还不足以说明引用正确。

### 原书编号与外部来源

- 当前讲义的动态编号与原书固定编号分开。明确指原书时可写“教材定理 2.1”，这不是当前文档的交叉引用；用户要求保留的原题号、定义号也不可因编号重构而丢失。
- 公式若必须保留教材编号，可使用适当的 `\tag` 并配合真实可引用的环境及 `\label`，检查编号唯一性，不普遍手工覆盖自动编号。
- 外部文献需要公开引用时，使用项目已有 BibTeX/biblatex 及 `\cite` 等机制；不要写伪引用或不存在的 key。未采用文献系统时按任务选择合适方式，不以 `\ref` 代替文献引用。
- 教材/PPT 的工作来源页码默认放 TeX 注释。需要供读者使用的公开来源说明则按用户要求保留；“去编辑痕迹”不等于删除所有学术归属。

检查编译日志中的 undefined references/citations、multiply-defined labels，并实际查看编号和跳转目标。可编译不意味着标签绑定正确，尤其要检查手写标题、计数器作用域及教师/学生版本的引用。
