## 来源注释

保留章节开头 `% !TeX root` 与来源说明，局部增加可追踪注释，例如：

```tex
% 来源：教师 PPT 第 26 页，摘录整理；以净交易量统一买卖意愿记号。
\begin{tcolorbox}[example,title=课堂例题：开盘报价与市场出清]
上午……
\end{tcolorbox}
```

来源页码与编辑过程默认不出现在例题标题和正文中。若存在影响结论的原题矛盾，保留必要的内容说明；不可把实质性不确定性藏进注释后将正文写成确定结论。

## 构建

在项目根目录，遵循当前 `AGENTS.md`、`.latexmkrc` 与既有脚本：

```sh
latexmk -xelatex 金融经济学_王江_讲义及习题.tex
tools/latex/build-dual.sh 金融经济学_王江_讲义及习题.tex output build/金融经济学_王江_讲义及习题
```

成品在 `output/`，辅助文件在 `build/`；双版本脚本生成教师版与 `_student_version.pdf`。按实际版本检查日志与页面，尤其注意解答留白造成的分页差异。使用 PDF 或演示文稿相关技能时遵循当前可用技能的操作要求。
