# 项目来源与构建

以下路径相对项目根目录。

## 入口与来源

- 主入口：`金融经济学_王江_讲义及习题.tex`；正文：`tex/金融经济学_王江/`；习题通常为同目录 `*_习题.tex`。
- 教材：`references/金融经济学/金融经济学-王江_261013.pdf`。
- 教师课件优先直接查看 `references/金融经济学/` 中已有的对应 PDF；第七讲为 `references/金融经济学/金融经济学_第7章 风险厌恶.pdf`（32 页）。需要追查页面疑点或没有 PDF 时，再查同目录的 PPTX。不要假设每章都有课件；用户补充的板书或截图也可作为来源。
- 答案参考：`references/金融经济学/史上最全最完整的金融经济学答案(王江版).pdf`。
- 勘误：`references/金融经济学/金融经济学教材勘误2021_原格式.docx`，相关内容有疑点时核对。
- 第二章可作为排版参考，不能把其现有内容视为不可更改的模板。其他项目的讲义仅在用户指定比较时参考，不引入源码依赖。

教材印刷页与 PDF 物理页分开记录。第二章已核对的起始对应为：印刷第 7 页对应 PDF 第 22 页；每次仍检查目标页面，避免把偏移推广到所有文件。

按截图文字、公式、标签或章节标题先定位 TeX，再打开相关来源页。整章复核可一次定位该章的教材和课件范围，逐页核对，记录实际页码及未核对象。后续轮次沿用这些位置和已确认的结论；来源、相关源码或问题范围变化时补查对应部分。已有可读的课件 PDF 可直接复用。

## 来源注释

保留章节开头 `% !TeX root` 与来源说明，局部增加可追踪注释，例如：

```tex
% 来源：教师 PPT 第 26 页，摘录整理；以净交易量统一买卖意愿记号。
\begin{tcolorbox}[example,title=课堂例题：开盘报价与市场出清]
上午……
\end{tcolorbox}
```

来源页码与编辑过程默认不出现在例题标题和正文中。若存在影响结论的原题矛盾，保留必要的内容说明；不可把实质性不确定性藏进注释后将正文写成确定结论。

## 单章预览

需要反复调整图、长框或局部分页时，在项目根目录运行，参数为主文件中的章节号。

```sh
python3 tools/latex/preview-wj-chapter.py 3
python3 tools/latex/preview-wj-chapter.py 3 --dual
```

默认输出教师版。需要看题面、答案隐藏或学生版留白时加 `--dual`。预览从正式主文件读取导言区，并加载该章及其引用的习题和图。生成的入口与缓存位于 `build/wj-preview/`，PDF 位于 `output/wj-preview/`，按章分目录。连续修改同一章时复用目录。多个会话同时预览同一章时，给各会话不同的 `--work-dir`，并在各自后续轮次复用。

预览从该章开始排页，省略全书前置页与其他章节。指向省略章节的引用可能显示 `??`，应确认目标确在其他章节。章内未定义或重复标签、缺字和排版错误仍需处理。若用户也要看单章，在 Cursor 另开该预览 PDF 标签页，后续构建写回同一路径。需要全书页码、目录、跨章编号或链接落点时，使用完整入口。

## Cursor 预览与完整验收

全书阅读标签页对应 `output/金融经济学_王江_讲义及习题.pdf`。在 Cursor 保存源码时沿用 LaTeX Workshop 的 `onSave`。Codex 修改可见内容后，默认用第一条命令更新同路径 PDF，并核对本轮改动已出现在其中。Cursor 已在编同一份 PDF 时先等该构建完成，确认它使用的是本轮源码。需要正式双版验收时用第二条命令。

```sh
tools/latex/build-dual.sh --teacher 金融经济学_王江_讲义及习题.tex output build/金融经济学_王江_讲义及习题
tools/latex/build-dual.sh --parallel 金融经济学_王江_讲义及习题.tex output build/金融经济学_王江_讲义及习题
```

以上两条命令共用教师版缓存，并按辅助目录互斥。前一轮完成后，后续构建才由 latexmk 判断是否需要重编。并行模式分别保留两版日志和辅助文件，两版都成功时才报告双版构建成功。默认串行调用仍可用。定稿验收前确认磁盘源码与交付范围一致。有并行编辑或只验证拟提交改动时，使用相应源码快照及独立的输出和辅助目录。涉及仅习题模式时，按项目 README 的命令另验。

项目的 `.vscode/settings.json` 按入口相对于仓库根目录的位置设置 LaTeX Workshop 的输出和辅助目录。讲义仍使用 `output/` 和 `build/<主文档名>/`，Beamer 使用 `output/Beamer/` 和 `build/Beamer/<课件名>/`。XeLaTeX recipe 从仓库根目录运行构建脚本，与终端使用相同路径。讲义学生版使用独立缓存。

## 图源与缓存

新增独立 TikZ 图使用 `tex/金融经济学_王江/figures/两位章号_图意.tex`，例如 `figures/12_资本市场线.tex`。图源首行设 `% !TeX root = ../../../金融经济学_王江_讲义及习题.tex`。在章节中写 `\WJInputFigure{12_资本市场线}` 即可接入缓存。新增图的图注、编号和引用放在章节，图面依赖的共享样式放在 `tex/_shared/`。需要使用正文当前位置、动态引用或跨图节点的绘制保留在章节原处。普通表格使用原生 LaTeX 排版。

正式入口通过 Memoize 缓存独立图源中的 TikZ 绘图，XeLaTeX 首次绘制时生成矢量图件，`xdvipdfmx` 从中提取缓存并完成排版。教师版、学生版和单章预览使用各自的辅助目录和缓存。改正文时复用图件，改图源时重建对应图件，改共享样式或项目字体时重建受影响的构建缓存。缓存文件随 `build/` 保留在本地。现有 Cursor recipe 和全书 PDF 路径可直接使用。

改变图缓存规则时，在隔离副本中核对首次构建、复用、图源变更和共享样式变更。检查正式教师版与学生版的图页、图注、页数和引用，并确认实际交付的 PDF 已完成最后一轮排版。

## 定位与渲染

用当前版本的 SyncTeX 或 `pdftotext -layout` 定位改动在 PDF 的物理页。教师版和学生版分别定位。用 `pdftoppm` 渲染目标页及受影响的相邻页，例如：

```sh
mkdir -p tmp/pdfs/wj-review
pdftoppm -f 6 -l 7 -scale-to 1500 -png \
  output/wj-preview/wj-ch03-preview/wj-ch03-preview.pdf tmp/pdfs/wj-review/ch03
```

检查公式、框、图、页边界与学生版留白。涉及目录、编号或跳转时，在对应完整 PDF 检查显示结果和链接落点。报告实际渲染页、构建模式、已知警告及正式成品的刷新状态。

原始资料、生成 PDF 和编译缓存仅本地保留，按仓库约定管理。skill 本身可跟随项目维护，不复制教材、PPT 或生成成品进 skill。保留用户已有修改，本工作流不包含自动提交、推送或发布。
