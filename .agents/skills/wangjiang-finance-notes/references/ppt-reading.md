# PPT 可读性与完整性核验

## 共用核对版本：课件 PDF

优先直接查看用户提供或项目已有的课件 PDF。第七讲为 `references/金融经济学/金融经济学_第7章 风险厌恶.pdf`，共 32 页；2026-11-06 抽查中文正文、图形和公式页可读。整章检查仍须逐页核对实际内容。用户提供的 PDF 是阅读入口，不要求每次打开 PPT 或重做导出；只有 PDF 缺页、显示异常、内容有疑点或需要动画与备注时才追查原稿。

没有可用课件 PDF 时，优先用原生 PowerPoint 本地导出为 PDF，检查合格后作为后续会话共用的页面核对版本。原 PPT 保留，用于核查动画顺序、备注、重叠对象或转换疑点。已知源 PPT 更新而 PDF 未更新时重新导出，不继续沿用旧缓存。

- 本机使用“文件 → 导出 → PDF → 最适合打印”，保存到 `tmp/pdfs/` 的课件核对目录，不覆盖教材或正式讲义 PDF。该选项本地处理；不选择标有 Microsoft 联机服务的电子分发选项。
- 记录源文件路径及散列（或修改时间）、导出方法、PDF 路径与页数，便于后续确认共用版本对应当前原稿。核对幻灯片总数与 PDF 页数；有隐藏页或选择范围时查明差异，并覆盖本轮所需页面。
- 先抽查中文密集页、公式页、关键图形页，确认中文、上下标、图注与对象完整，再按目标章节逐页阅读。动画分步或静态重叠导致信息不全时回到原生放映查看并补充截图。
- 已有相同源文件且通过上述检查的导出 PDF 时直接复用；不要每轮重新使用默认转换器。没有原生应用时才使用下面的备用流程，并明确剩余未核对象。

## 备用方式：修复 LibreOffice 字体

本项目的 PPT 常指定宋体、仿宋、楷体、黑体等字体。当前 bundled LibreOffice 默认转换时，可能只剩英文、数字、标点，中文标题和整段正文消失；图片中的中文却仍正常。进程退出码为 0、PDF 页数正确，也会发生这种情况。2026-11 的第五至第七讲检查缓存中已出现；早期第二讲会话曾修复临时副本，后续没有复用该办法。旧缓存不能直接作为“完整查看”的依据。

备用转换时已实测有效的字体修复办法是：给转换进程显式设置 `FONTCONFIG_FILE`，载入项目 `fonts/`，将中文字体映射到思源宋体、思源黑体或项目楷体。只作用于当前进程，不更改原 PPT、不安装或修改系统字体。它不修复全部对象兼容问题，不能替代原生 PDF 的完整性检查。

从项目根目录运行：

```sh
python3 .agents/skills/wangjiang-finance-notes/scripts/render_ppt_readable.py \
  'references/金融经济学/金融经济学_第7章 风险厌恶.pptx' \
  --outdir tmp/pdfs/ppt-readable
pdftoppm -f 12 -l 12 -scale-to 1600 -png \
  'tmp/pdfs/ppt-readable/金融经济学_第7章 风险厌恶.pdf' \
  tmp/pdfs/ppt-readable/check
```

脚本依赖可用的 `soffice`；找不到时先查询当前 workspace dependencies，也可用 `--soffice` 指定实际可执行文件。不要把某次 runtime 缓存绝对路径写死进 skill。该办法已验证第七讲第 12 页的中文标题、正文和 CE 图注恢复；其他页面仍须目视确认。

## 对象仍缺失时使用原生页面

字体修复后的第二讲第 42 页，LibreOffice 仍未显示大部分内容；已用本机 Microsoft PowerPoint 原生查看及本地 PDF 导出验证，原稿实际包含完整的小结。此类异常应切换渲染器，反复更换字体不能代替对象核验。

- 本机应用位于 `/Applications/Microsoft PowerPoint.app`；换机器先确认是否可用。通过当前可用的 computer-use 工具打开原稿，只查看或导出，不保存覆盖 PPT。
- 需要批量核对页面时，可用“文件 → 导出 → PDF”，保存到 `tmp/pdfs/` 的核对目录。选择“最适合打印”的本地导出；“最适合电子分发和辅助功能”标有使用 Microsoft 联机服务，不用于这一本地检查流程。
- 导出后核对页数，再渲染刚才缺失的实际页，确认中文、图形和公式已恢复。不要把一次成功导出推广为所有页面、所有对象均正确；仍按目标章节逐页检查，动画表达的信息必要时在原生放映中补看。

## 开始核对前

1. 先查看已有课件 PDF 的实际页面。需要诊断缺失对象或重新转换时，再清点 PPT 页数及对象：结合 OOXML 的文字、图片关系、原生形状、公式、WMF/EMF/OLE 和必要的备注。XML 文字列表不包含所有图内文字；图片数量也不是插图数量。
2. 用可读渲染抽查中文正文密集页、数学公式页及图形页，与原文件提取的文字对应。留意方框、只剩标点、大片异常空白、图注消失、上下标错位、文字公式重叠和对象遗漏。抽查用于验证渲染工具；用户要求整章核对时，仍应覆盖该章全部相关页面。
3. 出现异常即修复转换，并重新检查受影响页。原生导出有疑点时先回查原 PPT；备用 LibreOffice 转换先用上述字体配置。若仍异常，可在临时副本中替换中文字体，再转换并核验，或用可用的原生 PowerPoint/Keynote 查看。替换字体可能改变换行，不覆盖原文件，也不把该副本作为原始排版证据。保留原来的数学与符号字体。
4. 字体修复不能保证 WMF/EMF/OLE 都已恢复。对仍缺失或含歧义的对象，追踪对应 slide 的关系文件并检查原对象、内嵌预览或原生应用截图。仅恢复出位图的脚本会漏掉纯矢量对象；不要把保存了 `.emf` 文件误报为已经读懂该对象。

## 形成结论时

- 区分“已提取文字”“已恢复图片/公式”“已查看完整页面”。在临时核对记录中保留源文件、页码、渲染方法和未解决对象；来源覆盖结论与实际检查方式一致。
- 遇到旧会话声称已全面核对，先检查其实际缓存和操作。旧预览缺字时，保留教材、原生图片及文字提取支持的具体发现，用修复后的页面补核教师补充内容；不沿用笼统的“无遗漏”结论。
- 检查图示时，对照“原图—现有 TeX—处理方式”：TikZ 已转绘、已合并到另一图、已等价改为表格/公式、缺少图示分别记录。另列适合新增的教学可视化，不把建议图冒充原图遗漏。
- 找不到完整 PPT 的章节按现有照片或板书记录覆盖范围；不从其他章节推断教师材料齐全。预览仍不完整时，明确具体未核页或对象，再继续不依赖它的核对。
