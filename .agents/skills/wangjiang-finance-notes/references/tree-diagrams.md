# 树图规范与推荐参数

## 两类图式

| 类型 | 表达对象 | 视觉结构 |
| --- | --- | --- |
| 单期状态树 | 当期值及下一期各状态的禀赋、消费或证券支付 | 水平干线、竖向分叉、水平支线；右侧按状态列出结果 |
| 多期二叉树 | 多个时点的股价演化、期权支付与逐节点倒推 | 每个时点一列，具名节点之间用斜线箭头连接 |

按时间结构选择，不按正文、题目或解答的位置选择。单期树可以包含两个以上状态；多期树中，只有股价与同时列出股价、期权价值是同一风格下的内容布局变化。

多期的重合树与保留路径的树是模型结构差异：后续支付和决策只依赖当前状态时，可在题意允许下合并等价节点；历史路径影响支付或决策时，保留相应路径。当前股价相同本身不足以判定节点可合并。整理原题时保留其状态顺序、概率、支付和路径与解答的对应关系。

## 单期状态树

优先沿用项目 `\WJEventTree[选项]{结果列表}`。根节点和叶标签统一使用数学轴对齐的锚点（现有实现为 `mid east`、`mid west`），使水平线对齐数字的数学轴；避免以叶标签基线加固定上移量来补偿。竖干从首个分支连至最后一个分支，支线与标签之间留出间距。

| 参数 | 推荐起点 | 按内容调整 |
| --- | --- | --- |
| 状态行距 `row sep` | `1.7em` | 分数、较高公式或多行标签可增大，如 `2em` |
| 水平支线长度 | `0.7em` | 与字体、标签留白协调 |
| 当期干线长度 | `0.85em` | 当期标签较长时检查整体宽度及并排图间距 |
| 线宽 | `0.4pt` | 与正文图表的视觉重量协调 |

```tex
\WJEventTree[left={$e_1{:}100$}]{0,0}
\WJEventTree[left={$\tfrac12$},row sep=2em]{\tfrac32,\tfrac12}
```

`left` 表示当期标签，`stem` 可在没有当期标签时显示左侧干线；一个结果内部含英文逗号时用花括号分组。检查数字、分数、上下标和长概率标签，以及表格内多树并排的实际效果。

## 多期二叉树

先放置具名节点，再连接父节点的 `east` 与子节点的 `west`，让边从节点边缘出发并保留间距。题目图呈现原给定数据；解答图需要同时列出两种价值时，股价放上行、期权价值放下行。时点标签置于各列下方、同一水平线上。采用紧凑布局时优先调整空白和间距，保持文字清晰。

| 参数 | 推荐起点 |
| --- | --- |
| 字体 | `\small` |
| 时点列距 | `2.3cm` |
| 纵向网格单位 | `0.78cm` |
| 双行节点的基线间距 | `10.5pt` |
| 节点水平／垂直内边距 | `2pt`／`1pt` |
| 节点外边距 | `1pt` |
| 节点最小宽度／高度 | `7mm`／`5mm` |
| 连线宽度 | `0.45pt` |
| 箭头长度／宽度 | `1.5mm`／`1mm` |

这些值是推荐起点，不是固定要求。按节点标签长度、行数、数学符号高度、期数及可用页宽调整；双行基线间距还需与实际字号匹配。只有单行股价时可进一步收紧；标签较长或多行时适度放宽。不要为套用参数压缩到箭头过短、文字相撞，或只靠整图缩小解决布局问题。

### 归一化网格的使用

现有 `WJ binomial compact` 样式设置 `x=2.3cm,y=.78cm`。坐标应使用列索引等归一化数值：例如两期重合树的根为 `(0,0)`，中间层为 `(1,1)`、`(1,-1)`，末层为 `(2,2)`、`(2,0)`、`(2,-2)`。这里相邻列实际相距 `2.3cm`；不要再把列坐标写成旧布局的 `3`、`6` 而重复放大距离。

四路径的两期示例可取中间层 `(1,±1.25)`，末层 `(2,±2)`、`(2,±0.6667)`；这只是示例坐标，不是所有多期树的固定模板。时点标签可从 `y=-2.65` 起调，使其位于最低节点下方并留出间距。

## 项目实现与验证

以下路径相对项目根目录：

- 共用宏与样式：`tex/_shared/wj-tree-styles.tex`。
- 可编译示例：`tools/latex/examples/wj-tree-design.tex`，含单期及多期布局。

复用当前项目实现，修改前检查实际定义及调用，不重复定义宏。431 样式的参考关系不构成外部源码依赖，不从其他仓库绝对路径加载宏。

修改共用样式后，检查受影响的调用及相邻分页，覆盖两状态与多状态、分数、长标签、并排图、单行和双行多期节点。按任务需要构建教师版与学生版并渲染实际页面，核对标签对齐、节点与箭头间距、页宽、题图及学生留白。图形调整不改变数值、概率、模型结构或解答含义。
