# 王江金融经济学讲义整理

目标是形成可独立阅读、便于理解和复习的讲义：提炼关键概念，理顺知识关系，展开必要推导，完整呈现例题并梳理习题。

## 范围与入口

- 遵循当前项目的 `AGENTS.md`，先确认用户指定的章节、工作模式与现有未提交修改。
- 用户要求“仅分析”时只分析；要求修改时完成相应源码修改与验证。局部修订无需重做整章，也不自动扩展到其他章节。
- 首次处理本项目或需要定位来源、构建入口时，读 [项目来源与构建](references/project-sources.md)。整理文字、公式、证明和引用时，读 [写作与数学表达](references/writing-and-math.md)。
- 本 skill 是整理规则，不是对现有讲义正确性或源文件完整性的证明。每次以当前文件和实际来源为准。

## 工作顺序：先来源与结构，后修订与润色

整章检查、润色或优化按以下顺序进行：

1. **先核对来源并分析。** 先读王江教材 PDF 和教师课件 PDF 的相关完整页面，再对照现有 TeX。理清知识依赖与目录层级，检查关键定义、条件、命题、证明、例题、习题和图表有无遗漏；形成简明的层级调整、内容补全和图表处理结论。完成这一步后才进入其他检查与润色，不能以现有讲义为唯一依据直接改写。
2. **再实施修订。** 依上述结论调整层级、补全或校正内容，转绘关键图表并补上正文引用；随后检查跨章一致性、证明、公式、加框和表达，优化过度防御性表述。检查中发现新的来源疑点时回查原文。
3. **最后验证成稿。** 检查图表与正文的对应、自动编号和引用跳转，再完成教师版、学生版编译及实际排版检查。

用户只要求分析时，完成第 1 步并报告；已授权修订时，按分析结论继续，不额外等待确认。局部任务只核对直接相关的来源与依赖；本轮之前已完成、来源及相关 TeX 未变的核对可复用，并明确覆盖范围。

## 核对来源，提炼内容

1. 先阅读指定章节的教材相关完整页面及对应课件 PDF，再对照现有 TeX。教材用于核对正式概念、条件、命题、例题和习题；课件与板书用于识别教学重点、直观解释和课堂推导。
2. 用户提供或项目已有课件 PDF 时直接逐页查看 PDF；第七讲使用 `references/金融经济学/金融经济学_第7章 风险厌恶.pdf`。按实际页面核对公式、图形和文字，不以文字提取代替公式核验。PDF 缺失、内容不完整或涉及动画、备注等疑点时，再按 [PPT 可读性与完整性核验](references/ppt-reading.md) 检查原 PPT 或导出；不因常规阅读重新导出或逐轮检查 PPT 文件散列。
3. 按“原始内容—现有位置—遗漏或问题—处理方式”检查覆盖情况，尤其关注关键假设、等价条件、例题数据和全部原题。简单局部任务可直接完成核对，无需另建报告。
4. 保留原题数据、题号和重要记号。教材与 PPT 不一致时，分清记号替换、假设差异、简化与错误；实质性矛盾应记录并说明，不静默改成一致。确有必要统一记号时，核对维度、含义和前后依赖，并在源码注释保留来源对应。
5. 取舍服务于理解：定义说明对象，定理写清条件和结论，讲解说明联系与经济含义。补充内容放在前置知识之后，避免把提炼变成只抄结论或把补充变成提前讲完整个后续章节。

## 前后与跨章一致性

- 编辑前，检索本章沿用的核心概念、变量、假设和公式在前文的首次定义及相关后文用法；按依赖有针对性地阅读，不要求每次重读全书。前文 TeX 与教材、勘误相互核对，已有讲义不是唯一正确性依据。
- 检查定义的适用范围、假设强弱、公式条件、符号含义及维度、向量行列约定、上下标、时间与状态索引、随机变量记法、价格与收益率口径，以及总持仓和净交易等对象是否前后一致。公式表面相似不足以证明口径一致。
- 新增记号先查已有约定，优先沿用。区分全书约定、章节内模型和例题局部记号；局部重定义要在使用处清楚界定范围。同一符号在不同模型中的合法复用不机械替换，含义冲突则消除歧义或说明对应关系。
- 引用前文定理或公式时核对其假设在当前模型中是否满足；从特殊情形推广到一般情形、从单期到多期、从确定性到随机情形时，重新检查结论成立条件。不得把特殊形式或更强假设下的结论直接沿用为一般结论。
- 改动定义、假设、变量含义或核心公式后，检索依赖它的解释、证明、例题、习题解答与引用；在当前授权范围内同步修正，超出范围的影响具体报告，不能只改定义处便宣称已统一全书。必要时在源码注释保留记号映射或未解决依赖，正文保留读者真正需要的模型转换说明。

## 标题承担层级，框突出内容

- 以 `\chapter` 或项目章命令、`\section`、`\subsection`、`\subsubsection` 表示真实层级。原书 A/B/C/D 按内容归属转换为正式标题，不能机械将所有字母或加粗词升为同级标题。
- 编号体现上级位置，如 `2.3`、`2.3.5`、`2.3.5.2`；根据需要使用四段编号，不强制每段都设标题。独立主题不应仅靠星号标题或加粗段落掩盖其归属。
- 正式定义、核心假设、公理与关键定理加框。例题、课堂算例独立加框，完整交代情境、数据和问题，并使解答与题目连贯。
- 重点总结、补充知识可加框。普通解释、推导和证明通常放正文，紧随所解释的内容。
- 不把整节正文包进外框，不用框内嵌框表示层级。问题不在于框的数量，不设机械的每页或每章数量限制。
- 使用项目已有样式；调整作用域限于当前任务，检查目录、书签、编号和后续章节是否受影响。

## 图表覆盖与正文引用

- 来源核对时同时检查关键图表，按“原图及页码—现有 TeX 位置—处理方式”辨认已转绘、已合并、已等价呈现和遗漏；区分原图遗漏与适合新增的教学可视化。关键图形用 TikZ 转绘，数据或比较表用原生 LaTeX 表格；已有等价且清楚的表达不重复录入。
- 转绘保留原图的数学与经济含义，包括坐标、集合记号、向量箭头、分期与分状态的向量结构、曲线、点、概率及支付。配色和布局沿用本项目现有风格，可借鉴 431 计算讲义；改进视觉效果时不省略表达概念所需的符号和关系。
- 检查正文是否在对应概念、推导或结论处提到图表，并说明读者应观察的关系。图下说明不能代替正文引用；新增或重画图表后同步检查引用，不能等到排版结束才补。
- 需引用的图表使用项目已有的自动编号机制，标签绑定真实计数器，正文用 `图~\ref{fig:...}`、`表~\ref{tab:...}`。缺少编号机制时先接入合适的图表计数器或图注命令，不在普通段落、无编号图形旁直接放 `\label`，不手写当前讲义图号。语法和示例见 [写作与数学表达](references/writing-and-math.md)。

## 树图按时间结构选型

- 采用两类图式：单期状态树用水平分叉呈现下一期各状态结果；多期二叉树用斜线连接按时点分列的节点。两类均可用于正文、题目和解答。
- 多期图只有股价或同时包含股价、期权价值时，沿用同一视觉风格，按标签内容调整布局参数。重合树与保留路径的树属于模型结构差异，由支付的路径依赖及题意决定。
- 使用项目已有树图宏和样式，推荐参数作为布局起点，可随标签长度、行数、状态数、期数和页面宽度调整。处理树图时读 [树图规范与推荐参数](references/tree-diagrams.md)，并以实际渲染检查对齐、连线和可读性。

## 证明完整性

- 先辨认命题是单向蕴含、充要条件、多个条件等价，还是附加假设下的结论；保留“当且仅当”的逻辑强度。
- 对需要详细讲解的关键充要命题，分别写完整充分性与必要性。用 `（条件 A ⇒ 结论 B）` 和 `（结论 B ⇒ 条件 A）` 标明起点、目标，避免充分/必要标签与箭头对应错误。
- 多个条件等价时，给出覆盖全部条件的双向证明或完整闭环；单向命题不擅自补成等价关系。逆命题不成立时，可用必要的反例解释边界。
- 展开关键跳步：变量定义、构造动机、代入、等式或不等式依据，以及最后如何得到原结论。不能用“显然”“同理”替代尚未证明的另一个方向。
- 核对每一步用到的条件，如定义域、可积性、最优解存在性、边界、可行集合和交易限制。需要补充假设时明确说明；证明缺口未解决时记录待核验，不宣称已完整证明。
- 充分性与必要性两边的假设、量词、比较对象和符号含义须一致；补充假设后的结论不能冒充原命题。

## 成稿表达、公式与引用

- PDF 正文应像独立成稿。来源页码、摘录整理、记号调整理由和修订记录放 TeX 注释；去掉“课件情境”“用本章记号说明”“对应定义”等编辑性引导，直接接续例子和推导。
- 润色泛泛的防御性措辞，改为具体概念解释；保留结论成立所需条件。不是机械删除“不”“不能”，也不能为流畅而消除数学区别。
- 行间公式后开始新的说明段、证明步骤或结论段时，在关闭公式环境后空一行，使正文按项目样式正常首行缩进；仅换行仍是同一段。按语义区分新段与原句续写，具体示例见 [写作与数学表达](references/writing-and-math.md)。
- 按需用 `\underbrace{...}_{...}` 建立公式项与经济含义或已定义对象的对应，优先用于难懂的分解、预算约束、出清条件和证明关键组合。注释简短、准确，不逐项装饰；长解释放正文。详见参考中的示例和版面规则。
- 内部引用使用正确的 LaTeX `\label`、`\ref`、`\eqref` 等机制；跨章也不手写当前文档编号。引用必须绑定真实计数器，不能给手写粗体“定理”随意加 `\label` 后假装已正确编号。
- 保留原有编号引用，以维持前后知识结构的联系。仅有编号、读者需回翻才知道所指条件或结论时，在编号后加简短括号解释，例如“公理~\ref{...}（连续性）”“问题~\eqref{...}（预算约束下的效用最大化）”；不以解释替换编号。紧邻正文已明确展开所引内容时不重复添加；较长背景说明可用脚注。整理其他章节时同样检查此项，并核对解释与被引内容及适用条件一致。
- 区分当前讲义交叉引用、教材原编号及外部文献引用；根据项目已有设施处理，详见参考。编译核查目标、显示编号及超链接，不能只确认语法可编译。

## 完成检查

- 内容：关键知识与习题覆盖充分；原题数据不误改；记号、条件、推导和充要方向一致。
- 前后关系：本章沿用的定义、公式与变量符合前文约定；模型变化交代清楚；核心修改对后文依赖的影响已检查，未处理部分明确列出。局部检查结果不表述为全书已核验。
- 结构：内容归属清晰，标题编号正确，无整节外框或嵌套框；正文无编辑痕迹。
- 数学表达：公式可读，underbrace 对齐准确；引用目标真实、唯一且类型正确。
- 图表：关键原图已转绘或有等价呈现，必要符号与结构完整；新增教学图适合当前知识位置；正文引用、图表编号及超链接目标一致，图形与图注分页连贯。
- 树图：单期标签与支线对齐，多期节点按时点分列，连线与文字留有间距；原状态、路径、概率与支付保持正确，推荐参数已按实际内容检查。
- 实施 TeX 修改后按项目入口构建所需版本；通常检查教师版与学生版。检查错误、缺字、溢出、未定义或重复标签，并渲染实际变更页及相邻分页，确认长框、公式、目录、学生版留白正常。
- 最后简述修改范围、验证结果和仍待核验之处。仅修改本 skill 时运行 skill 校验并检查内容，不为此重编译未改动的讲义。
