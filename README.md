本仓库整理两套金融经济学学习资料：

资料用于课程学习与复习，解答和整理内容可能存在疏漏，使用时可结合教材和课堂资料核对。仓库提供 LaTeX 源码，不包含生成的 PDF；可按下方说明自行编译。

## 编译

需要 XeLaTeX、latexmk 和包含文档所需宏包的 TeX Live / MacTeX。中文字体以及定制 exam-zh 运行时随仓库提供。
在仓库根目录执行：

```sh
latexmk -xelatex 金融经济学_王江_讲义及习题.tex
latexmk -xelatex 金融经济学_熊和平_习题.tex
```

讲义 PDF 写入 `output/`，中间文件写入 `build/<主文档名>/`。从根目录编译 `Beamer/` 的课件时，PDF 写入 `output/Beamer/`，中间文件写入 `build/Beamer/<课件名>/`。课件入口见 [Beamer 构建说明](Beamer/README.md)。

教师版和学生版（脚本需要 zsh，并使用 macOS 上的 `/Library/TeX/texbin/latexmk`）：

```sh
tools/latex/build-dual.sh 金融经济学_王江_讲义及习题.tex output build/金融经济学_王江_讲义及习题
tools/latex/build-dual.sh 金融经济学_熊和平_习题.tex output build/金融经济学_熊和平_习题
```

王江仅习题版：

```sh
latexmk -xelatex -usepretex -pretex='\def\WJExercisesOnly{}' -jobname=金融经济学_王江_exercises_only 金融经济学_王江_讲义及习题.tex
```

王江精选作业解答：

```sh
# 默认：第6章第1、2、3题，第7章第1、4、5题，各输出一份 PDF
python3 tools/latex/export-wj-homework.py

# 自定义章节与题号，按参数中的题号顺序排版
python3 tools/latex/export-wj-homework.py 6:1,3 7:4,5

# 仅生成入口，供检查选题和源码
python3 tools/latex/export-wj-homework.py --prepare-only
```

脚本每次读取当前章节源码，复用正式入口的字体和排版定义。精选版连续排版、无页眉文字，标题仅保留章节名称；题干、原题号及星号与解答原文一并保留。PDF 写入 `output/pdf/`，生成入口与缓存写入 `build/作业精选/`，均不纳入 Git。脚本也可从其他工作目录通过绝对路径调用。

默认输出：

- `output/pdf/王江_第6章_作业解答_1-2-3.pdf`
- `output/pdf/王江_第7章_作业解答_1-4-5.pdf`

更新章节解答后，重新运行脚本即可更新这两份文件。
