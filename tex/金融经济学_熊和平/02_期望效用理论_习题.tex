\begin{problem}
\problemno{3} 若你具有对数效用函数，当前财富水平是 \num{5000} 元：
\begin{enumerate}[label=(\arabic*)]
    \item 假如你面临一个 $50/50$ 的概率获得或损失 \num{1000} 元的风险，购买 \num{125} 元的保险可以完全消除该风险，你选择购买保险还是进行该项投机活动？
    \item 若在 (1) 中进行了投机而且亏损 \num{1000} 元，你的财富变为 \num{4000} 元。面对 (1) 中的保险是再次投机还是购买保险？
\end{enumerate}
\end{problem}
\begin{problem}
\problemno{4} 考虑下面的四种彩票：
\[
    L_A=(x,\pi;0,1-\pi),\quad L_B=(y,\pi';0,1-\pi'),\quad L_C=(x,\alpha\pi;0,1-\alpha\pi),\quad L_D=(y,\alpha\pi';0,1-\alpha\pi'),
\]
其中 $0<x<y$，$\pi<\pi'$，$\pi x<\pi' y$，并且 $\alpha\in(0,1)$。
\begin{enumerate}[label=(\arabic*)]
    \item 若投资者在 $L_C$ 和 $L_A$ 之间选择 $L_C$，那么该投资者的偏好是否与冯·诺依曼-摩根斯坦的期望效用理论一致？为什么？
    \item 若投资者在 $L_A$ 和 $L_B$ 之间选择 $L_A$，在 $L_C$ 和 $L_D$ 之间选择 $L_D$，那么该投资者的偏好是否与冯·诺依曼-摩根斯坦的期望效用理论一致？为什么？
\end{enumerate}
\end{problem}
