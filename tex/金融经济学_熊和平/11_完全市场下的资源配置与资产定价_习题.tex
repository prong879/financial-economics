\xhpexercises
\begin{problem}
\problemno{1} 假设市场是完全的，在 1 期经济有 $3$ 个等可能的状态 $a$、$b$ 和 $c$；经济中有两个参与者 1 和 2，他们的禀赋分别为：
\[
    \text{参与者 1：}\begin{bmatrix}100\\0\\0\end{bmatrix},\qquad
    \text{参与者 2：}\begin{bmatrix}0\\100\\50\end{bmatrix}.
\]
他们的时间偏好都为 $1$，而且都具有 CRRA 效用函数，参与者 1 的相对风险厌恶系数为 $1$，参与者 2 的相对风险厌恶系数为 $2$。
\begin{enumerate}[label=(\arabic*)]
    \item 求解每一参与者的最优消费计划；
    \item 求解均衡状态价格；
    \item 求期末支付向量为 $(200;100;50)^{\mathrm{T}}$ 的股票的均衡价格。
\end{enumerate}
\end{problem}
\begin{problem}
\problemno{2} 给定 Pareto 最优配置及其最优风险分担规则 $f_i$，令 $T_i(z)=-u_i'(z)/u_i''(z)$ 为经济人 $i$ 的风险容忍函数，他在 $z$ 下的谨慎系数 $P_i(z)$ 表示为 $P_i(z)=-u_i'''(z)/u_i''(z)$：
\begin{enumerate}[label=(\arabic*)]
    \item 证明
    \[
        f_i'(z)=\frac{T_i(f_i(z))}{\sum_k T_k(f_k(z))}.
    \]
    \item $f_i$ 为线性的充要条件是：$\sigma_i(f_i(z))=\sigma_k(f_k(z))$，$\forall i,k,\forall z$。
\end{enumerate}
\end{problem}
\begin{problem}
\problemno{3} 对给定权重 $\lambda_i$，经济人 $i$ 的 Pareto 最优风险分担规则 $f_i$ 和 $f$，定义 $u_0$ 和 $u_i$ 满足 $u_0'(z)=\sum_i\lambda_i u_i'(f_i(z))$ 和 $u_i'(z)=\lambda_i u_i'(f_i(z))$，证明：
\begin{enumerate}[label=(\arabic*)]
    \item $u_0$ 和 $u_i$ 是严格单调递增和凹的；
    \item $u_0(C_0)+E[u_i(C_1)]$ 是代表性经济人的效用函数。
\end{enumerate}
\end{problem}
\begin{problem}
\problemno{4} 证明：如果每个经济人是绝对风险厌恶递减的（DARA），那么代表性经济人也是绝对风险厌恶递减的。
\end{problem}
\begin{problem}
\problemno{5} 两时点单期情形下，假设期末有两个状态 $\alpha$ 和 $b$，它们发生的概率分别为 $\pi$ 和 $1-\pi$。市场上有两只交易的证券 1 和证券 2，证券 1 是无风险证券，证券 2 是风险证券，支付向量为 $(uC,dC)$，其中 $C>0$，$0<d<u$。经济中有 $K$ 个经济人，经济人 $k$ 的禀赋是 0 期 $s_k$ 个单位的消费品和 $s_k$ 单位的证券 2，其中 $s_k>0$ 且 $\sum_k s_k=1$。所有经济人的效用函数为
\[
    U(c)=\ln c_{k,0}+\rho\bigl[\pi\ln c_{k,\alpha}+(1-\pi)\ln c_{k,b}\bigr],\qquad \rho>0.
\]
\begin{enumerate}[label=(\arabic*)]
    \item 证明证券市场是完全的；
    \item 求解每个经济人的最优消费-投资选择；
    \item 求两个证券的均衡解。
\end{enumerate}
\end{problem}
\begin{problem}
\problemno{6} 在第 5 题的框架下：
\begin{enumerate}[label=(\arabic*)]
    \item 将价格过程与期权定价中二叉树模型进行比较，可以得出什么结论？
    \item 构建代表性经济人；
    \item 计算代表性经济人的效用函数中每个经济人的权重。它依赖什么？为什么？
    \item 证明代表性经济人的偏好与禀赋在各经济人中的分布无关；
    \item 用基于消费的 CAPM 给两证券定价；
    \item 计算风险资产的股权溢价；
    \item 利率和股票形成的股权风险溢价依赖于什么？解释它们对当前消费水平、消费增长率的期望值 $E[C_1/C_0]$ 和波动率 $\operatorname{var}(C_1/C_0)$ 以及时间偏好率 $\rho$ 的依赖性；
    \item 求以证券 2 为标的资产、执行价格为 $K$ 的看涨期权的价格，并证明基于消费的 CAPM 也适用于期权。
\end{enumerate}
\end{problem}

\end{problem}
